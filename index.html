怎样使用这些教程？

推荐先阅读问题背景和图形示意，理解模型的输入、处理环节和输出；随后阅读实验实测与能力边界。如果需要复现，再进入 GitHub 工程目录及 Actions 链接查看版本、原始数字证据和独立验证程序。

证据约定：页面上的原创示意图是帮助理解机制的教学图，不冒充原始模型预测。真实实验是否执行成功，请以对应 GitHub Actions 和工程报告为准；小样本演示不等于模型质量基准或生产级性能认证。
