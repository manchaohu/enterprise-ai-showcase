01｜The problem to solve

Exact nearest-neighbor search compares every query with a full vector set. HNSW builds a navigable proximity graph to find approximate Top-k neighbors without performing the same exhaustive ranking path.

02｜How the technology works

The implementation constructs a native hnswlib HNSW graph index with cosine distance and integer IDs. NumPy exact cosine Top-10 acts as a reference; the independent verifier reloads the saved index and checks resulting IDs, distances and Recall@10.

03｜Actual experiment inputs

2,048 seeded normalized 48-dimensional synthetic numeric vectors form the corpus. The program executes 36 perturbed queries and saves the native index binary, source vectors, query IDs and per-query results.

04｜Observed result and independent evidence

Mean Recall@10 was 1.0 across 36 synthetic queries; eight tests, actual index construction, binary serialization/reloading and independent replay passed. This is a small constructed-vector result.

05｜Reproduce from the repository

Run this reference command in the documented engineering environment.

cd projects/22-hnsw-ann
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python hnsw_e2e.py
python verify_evidence.py

Source and Actions may require private-repository access; this public lesson contains no redistributed model weights or private data.

06｜What cannot be concluded

No pretrained text embeddings, large-scale latency benchmark or real enterprise vector distribution was assessed. Recall@10=1.0 on a synthetic fixture is not universal search quality.
