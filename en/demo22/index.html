Demo 22｜HNSW nearest neighbor index: recall and persistence

1. Requirements and acceptance

Index 2,048 synthetic 48-dimensional vectors in real hnswlib, issue 36 Top10 cosine queries, compare with exact brute-force nearest neighbors, and save/reload the binary index. This demonstrates ANN mechanics rather than neural embedding generation.

2. Technical design and data flow

Seed 20261020 produces normalized corpus and perturbed queries. HNSW builds with M=16 and ef_construction=120, searches with ef_search=100, and inserts with one thread. Build/query/exact-scan timing is recorded. Reloading the index requires resetting ef_search because it is not persisted.

3. Core code and implementation details

3.1 Construct HNSW cosine index

Source：hnsw_e2e.py — Selected excerpt, surrounding context omitted; not standalone executable

index = hnswlib.Index(space="cosine", dim=DIM)
index.init_index(max_elements=COUNT,
  ef_construction=EF_CONSTRUCTION,M=M,random_seed=17)
index.add_items(corpus, ids, num_threads=1)
index.set_ef(EF)
ann_ids, ann_distances = index.knn_query(queries,k=K,num_threads=1)

M controls graph connectivity, ef_construction affects build quality/cost, and ef_search trades search effort for recall/latency. The cosine space returns distance rather than similarity. Single-thread insertion improves reproducibility but is not a throughput benchmark.

3.2 Exact baseline and persistence check

Source：hnsw_e2e.py — Selected excerpt, surrounding context omitted; not standalone executable

exact = np.argsort(-(queries @ corpus.T),axis=1,kind="stable")[:,:K]
index.save_index(str(index_path))
reloaded.load_index(str(index_path),max_elements=COUNT)
reloaded.set_ef(EF)
after_ids, after_distances = reloaded.knn_query(queries,k=K,num_threads=1)
assert np.array_equal(ann_ids,after_ids)

The exact baseline ranks all corpus vectors and computes overlap/10 per query. SHA-256 ties evidence to vector and index files. Reload checks query equivalence, not cross-version binary compatibility or dynamic update correctness.

4. Observed results and evidence

Independent verification reports DEMO_SCOPE_PASS, mean/min Recall@10 of 1.0 over 36 queries. Observed exact scan 3.533ms, HNSW build 87.176ms and HNSW query phase 1.655ms for the tested queries. These one-run, small-set timings are not million-vector benchmarks.

5. Integration and operational use

Use in semantic/image similarity retrieval as the neighbor index behind an embedding generator. Add access filtering, index mutation, model-version migration and recovery. Benchmark M/ef settings and realistic distributions before choosing recall/latency targets.
