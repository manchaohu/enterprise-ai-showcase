1. Requirements and acceptance

Encode four English sentences with an actual pretrained sentence-transformer, compare same-topic paraphrases with unrelated text, and verify vector shape, L2 norm and repeatability. This demonstrates real neural embeddings on CPU rather than the TF-IDF/SVD latent vectors used in Demo 04.

2. Technical design and data flow

SentenceTransformer runs the paraphrase-MiniLM-L3-v2 checkpoint on CPU, encoding four texts as a [4,384] matrix. With normalized embeddings, the vector dot product yields cosine similarity. Input ordering and normalization are part of the contract. The model revision requests moving main rather than an immutable commit.

3. Core code and implementation details

3.1 Encode and normalize

Source：verify_embedding.py — Selected excerpt, surrounding context omitted; not standalone executable

model = SentenceTransformer(MODEL_ID, revision="main", device="cpu")
vec = model.encode(sentences, normalize_embeddings=True,
  convert_to_numpy=True, show_progress_bar=False)
assert vec.ndim == 2 and vec.shape[0] == 4
norms = np.linalg.norm(vec,axis=1)
assert np.allclose(norms,1,atol=0.01)

Normalization turns vector similarity into an angular comparison. NumPy output supports direct matrix arithmetic. The 0.01 tolerance permits floating-point error but does not establish semantic quality. Persist model identity, version and dimension with any vector index.

3.2 Cosine matrix and checks

Source：verify_embedding.py — Selected excerpt, surrounding context omitted; not standalone executable

scores = vec @ vec.T
assert scores[0,1] > scores[0,2]
assert scores[2,3] > scores[2,0]
again = model.encode([sentences[0]], normalize_embeddings=True,
  convert_to_numpy=True, show_progress_bar=False)[0]
assert np.allclose(again,vec[0],atol=1e-4)

Two inequalities test relative similarity without hardcoding score thresholds; the repeated encoding checks numerical stability. Real retrieval quality needs relevance-labeled Recall@k, nDCG and per-domain evaluation, not just two constructed contrasts.

5. Integration and operational use

In retrieval, add chunking, model-version pinning, throughput monitoring and index refresh. Query and document embeddings must share a compatible vector space; changing weights usually requires re-embedding. Neural vectors may complement BM25 and a separate reranker.
