01｜The problem to solve

A genuine text-to-image test must load pretrained diffusion weights and perform denoising, not draw a canned graphic. Recording seeds, schedule steps and image artifacts separates valid neural execution from subjective image quality.

02｜How the technology works

A pinned pretrained Segmind Tiny-SD checkpoint runs in Diffusers StableDiffusionPipeline on CPU. Each 256×256 output follows six actual denoising scheduler steps at guidance_scale=1.0, with seeds, callbacks, checkpoint identity and PNG hashes recorded.

03｜Actual experiment inputs

Two English prompts describe a red apple and blue mug on a table. Fixed seeds 172001 and 172002 drive two genuine image generations, with observed inference portions of 15.893 s and 15.822 s respectively, excluding installation/download.

04｜Observed result and independent evidence

Real pretrained inference, both PNGs, six denoising callbacks, independent file/hash checks and evidence JSON passed. Synthetic placeholder colored PNGs were not substituted for the diffusion pipeline.

05｜Reproduce from the repository

Run this reference command in the documented engineering environment.

cd projects/17-real-text-to-image
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python diffusion_e2e.py
python verify_evidence.py

Source and Actions may require private-repository access; this public lesson contains no redistributed model weights or private data.

06｜What cannot be concluded

Valid PNGs and actual denoising do not prove prompt adherence or visual quality; human inspection remains open. The Tiny-SD OpenRAIL-M license requires separate review for redistribution or commercial use.
