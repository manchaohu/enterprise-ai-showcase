YOLOv8n ONNX | Letterbox, box decoding, and NMS

A real pretrained YOLOv8n object-detection experiment: inputs, bounding boxes, ONNX CPU inference, independently checked outputs, and what they do not prove.

← Back to all tutorials

01 | The problem: image classification is not enough

A whole-image classifier can tell us the most likely category for a photograph, but many practical tasks ask a different question: which objects are present, where are they, and how many candidates did the system find? Consider a street photo containing a bus, pedestrians and background buildings. A single image label does not describe the locations of the objects.

Object detection predicts a category, confidence score and rectangular coordinates for each retained candidate. This is helpful when the downstream application needs to locate potential objects, though detection alone does not identify exact object outlines or guarantee correctness.

02 | What the output means

The experiment uses a real pretrained YOLOv8n network with COCO categories exported to ONNX. The model first evaluates many potential boxes, and normal postprocessing then decides which boxes should remain. These are separate responsibilities: network predictions are learned, while confidence filtering and non-maximum suppression (NMS) are explicit procedures applied to its outputs.

For this fixed experiment, the network input is 1×3×640×640, and its raw output has shape 1×84×8400. The final number of boxes is much smaller; 8,400 candidates do not mean that 8,400 objects were detected. The demonstration uses a confidence threshold of 0.25 and NMS IoU threshold of 0.45. Its result can be reproduced from the raw tensors and the recorded postprocessing settings.

Letterbox with reversible geometry

The source image is proportionally scaled into a 640×640 canvas. Scale and padding are retained so the predicted coordinates can be mapped back to the original image; the tensor is normalized float32 RGB in NCHW layout.

def letterbox(image: Image.Image) -> tuple[np.ndarray, dict]:
    rgb = image.convert("RGB")
    w, h = rgb.size
    if min(w, h) < 8:
        raise ValueError("source image too small")
    scale = min(INPUT_SIZE / w, INPUT_SIZE / h)
    nw, nh = round(w * scale), round(h * scale)
    left = (INPUT_SIZE - nw) // 2
    top = (INPUT_SIZE - nh) // 2
    padded = Image.new("RGB", (INPUT_SIZE, INPUT_SIZE), (114, 114, 114))
    padded.paste(rgb.resize((nw, nh), resample=Image.Resampling.BILINEAR), (left, top))
    nchw = np.asarray(padded, dtype=np.float32).transpose(2, 0, 1)[None] / 255.0
    return np.ascontiguousarray(nchw, dtype=np.float32), {
        "source_size": [w, h], "scaled_size": [nw, nh],
        "pad_left_top": [left, top], "scale": scale,
    }

Model output decoding and class-wise NMS

This export returns `[1,84,8400]` predictions: four box values and 80 class scores. The application applies a confidence threshold of 0.25, maps boxes into image coordinates, and performs per-class NMS at IoU 0.45, capped at 25 outputs.

def decode_detections(raw: np.ndarray, geometry: dict) -> list[dict]:
    if raw.shape != (1, 84, 8400) or not np.isfinite(raw).all():
        raise ValueError(f"unexpected or invalid real YOLO output: {raw.shape}")
    vectors = raw[0].T
    class_scores = vectors[:, 4:]
    classes = np.argmax(class_scores, axis=1)
    confidences = np.max(class_scores, axis=1)
    chosen = np.flatnonzero(confidences >= CONF)
    if len(chosen) == 0:
        return []
    centers = vectors[chosen, :4]
    net_boxes = np.column_stack([
        centers[:, 0] - centers[:, 2] / 2,
        centers[:, 1] - centers[:, 3] / 2,
        centers[:, 0] + centers[:, 2] / 2,
        centers[:, 1] + centers[:, 3] / 2,
    ])
    left, top = geometry["pad_left_top"]
    scale = geometry["scale"]
    w, h = geometry["source_size"]
    boxes = net_boxes.copy()
    boxes[:, (0, 2)] = np.clip((boxes[:, (0, 2)] - left) / scale, 0, w)
    boxes[:, (1, 3)] = np.clip((boxes[:, (1, 3)] - top) / scale, 0, h)
    results = []
    for class_id in sorted(set(int(x) for x in classes[chosen])):
        loc = np.flatnonzero(classes[chosen] == class_id)
        order = loc[np.argsort(-confidences[chosen[loc]], kind="stable")]
        while len(order) and len(results) < MAX_DETECTIONS:
            selected = int(order[0])
            box = boxes[selected]
            if box[2] > box[0] and box[3] > box[1]:
                results.append({
                    "class_id": class_id,
                    "confidence": float(confidences[chosen[selected]]),
                    "xyxy": [round(float(x), 3) for x in box],
                })
            rest = order[1:]
            if len(rest) == 0:
                break
            overlaps = iou_one_to_many(box, boxes[rest])
            order = rest[overlaps <= IOU]
    return sorted(results, key=lambda x: (-x["confidence"], x["class_id"]))[:MAX_DETECTIONS]

05 | The important limitations

The successful run establishes that actual model weights executed and that their numeric outputs passed the stated independent checks. It does not establish real-world accuracy, recall, robustness to changing scenes or suitability for safety-critical use. There was no independent manually annotated benchmark from which to calculate mAP/Recall. Detection boxes are not semantic or instance segmentation masks.
