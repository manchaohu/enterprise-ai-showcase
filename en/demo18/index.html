1. Requirements and acceptance

Classify word-level form roles from image pixels, dataset-provided OCR words and boxes with a FUNSD-finetuned LayoutLMv3. Two test forms validate multimodal forward passes, wordpiece alignment and BIO role predictions. OCR is not executed by this demo.

2. Architecture and execution path

Hugging Face Datasets loads test[:2]. AutoProcessor with apply_ocr=False encodes image pixels, tokens and normalized 0–1000 boxes. A seven-class token head outputs BIO logits. Wordpiece tokenization requires word_ids() alignment so each original word is counted once.

3. Core implementation

3.1 Validate OCR word and box alignment

Source：layout_e2e.py · Selected excerpt; full logic in repository

if len(words) != len(boxes) or len(words) != len(gold_tags):
    raise ValueError("Misaligned words / boxes / reference labels")
if (len(box) != 4 or any(type(x) is not int or
    not 0 <= x <= 1000 for x in box)):
    raise ValueError("Invalid normalized document bounding box")

OCR tokens, boxes and labels must align one-to-one. LayoutLM-style coordinates are normalized to 0–1000. Pixel boxes from a real OCR engine must be normalized against page dimensions, accounting for any crop or rotation.

3.2 Processor inputs and model forward pass

Source：layout_e2e.py · Selected excerpt; full logic in repository

processor = AutoProcessor.from_pretrained(MODEL_ID, apply_ocr=False)
encoded = processor(image, words, boxes=boxes, return_tensors="pt",
                    truncation=True, max_length=512)
with torch.inference_mode():
    logits = model(**encoded).logits
    probabilities = logits.softmax(dim=-1)

The OCR switch is disabled because FUNSD already supplies word boxes. max_length=512 can truncate large forms, although neither test sample was truncated. Softmax and argmax select one of seven roles; maximum score is not necessarily a calibrated business confidence.

3.3 Align wordpieces and evaluate roles

Source：layout_e2e.py · Selected excerpt; full logic in repository

aligned = first_wordpieces(encoded.word_ids(batch_index=0), len(words))
for pos, word_id in aligned:
    prob = probabilities[0, pos]
    label_index = int(prob.argmax().item())
    predicted.append({"word": words[word_id],
        "predicted_label": LABELS[label_index],
        "gold_label": LABELS[gold[word_id]]})

Selecting the first wordpiece per source word avoids duplicate counting. BIO marks span beginnings, continuations and unrelated tokens. Labels are not yet question–answer relations. The simple reference-match fraction is descriptive for the sampled words, not an end-to-end document extraction benchmark.

5. Integration and operational design

Reproduction commands (requires private repo access)

cd projects/18-document-layout
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python layout_e2e.py
python verify_evidence.py

A document system can feed OCR tokens and normalized boxes into a layout classifier, group BIO spans and then associate questions with answers using spatial or relational logic. This span assembly and field linking are not implemented here. OCR errors propagate into downstream role predictions.

6. Limits and evidence

Two FUNSD test forms only. Third-party image redistribution rights need review. OCR, key-value pairing, Chinese and business forms were not tested. The internal overlays show model predictions, not dataset ground truth.
