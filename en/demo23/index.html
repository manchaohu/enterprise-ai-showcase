Silero VAD ONNX | Speech probabilities and detected time spans

A real pretrained Silero VAD ONNX experiment: 844 neural probability frames, nine candidate speech spans, independent replay, and a chart derived from genuine outputs.

← Back to all tutorials

01 | Requirement: speech activity timestamps

A voice assistant or meeting recorder receives a stream that mixes speech, silence and background sounds. Sending every second to a speech-recognition model may consume unnecessary work; cutting too aggressively can lose useful utterances. The system needs a more basic clue: at what times is human speech likely present?

Voice Activity Detection (VAD) estimates likely speech intervals. It does not tell us which words were spoken or identify the speaker. It often serves as an upstream signal for speech-to-text, audio chunking or real-time turn-taking.

02 | Frame-wise neural speech probability

This experiment uses a real pretrained Silero VAD ONNX model. It takes 16 kHz mono audio in 512-sample frames, equivalent to 32 milliseconds per frame. The runtime preserves a small audio context and recurrent neural state between frames; the model produces a probability from zero to one for each frame.

The neural network supplies probabilities, while the application supplies the conversion from probabilities to time intervals. The demonstration applies a threshold of 0.50, merges gaps no longer than four frames, and requires a span at least six frames long. These are simplified teaching settings, not Silero's full official production segmentation procedure.

Frame-wise ONNX inference with persistent state

At 16 kHz, 512 samples represent 32 ms. The model receives 64 samples of retained context and a recurrent state tensor. The returned state is passed to the next frame; short final frames are padded. Input names, state dimensions, and probability bounds are checked.

def model_scores(model: Path, signal: np.ndarray) -> tuple[np.ndarray, dict]:
    import onnxruntime as ort

    options = ort.SessionOptions()
    options.intra_op_num_threads = 1
    options.inter_op_num_threads = 1
    session = ort.InferenceSession(str(model), sess_options=options, providers=["CPUExecutionProvider"])
    inputs = {x.name: x for x in session.get_inputs()}
    if set(inputs) != {"input", "state", "sr"}:
        raise AssertionError(f"wrong Silero ONNX inputs: {list(inputs)}")
    state = np.zeros((2, 1, 128), dtype=np.float32)
    context = np.zeros((1, CONTEXT), dtype=np.float32)
    scores = []
    tic = time.perf_counter()
    for i in range(0, len(signal), FRAME):
        chunk = np.asarray(signal[i:i + FRAME], dtype=np.float32)
        if len(chunk) != FRAME:
            chunk = np.pad(chunk, (0, FRAME - len(chunk)))
        model_input = np.concatenate((context, chunk.reshape(1, FRAME)), axis=1)
        outputs = session.run(None, {"input": model_input, "state": state, "sr": np.array(SR, dtype=np.int64)})
        if len(outputs) != 2:
            raise AssertionError("unexpected pretrained ONNX model output count")
        score = float(np.asarray(outputs[0]).reshape(-1)[0])
        state = np.asarray(outputs[1], dtype=np.float32)
        if state.shape != (2, 1, 128) or not math.isfinite(score) or not 0 <= score <= 1:
            raise AssertionError("invalid VAD state or probability")
        scores.append(score)
        context = model_input[:, -CONTEXT:].copy()

Thresholding, gap merging, and timestamps

Frames above 0.50 form candidates; gaps of up to four frames are merged and intervals shorter than six frames are discarded. Frame boundaries become seconds using the sample rate. These demo rules are distinct from Silero's official hysteresis implementation.

def segments_from_scores(scores: np.ndarray, sample_count: int) -> list[dict]:
    """Simple pedagogical threshold + short-gap merge; not Silero's official hysteresis."""
    if sample_count <= 0 or scores.ndim != 1 or len(scores) != math.ceil(sample_count / FRAME):
        raise ValueError("invalid frames vs audio length")
    if not np.isfinite(scores).all() or np.any(scores < 0) or np.any(scores > 1):
        raise ValueError("invalid VAD score distribution")
    high = np.flatnonzero(scores >= THRESHOLD)
    if len(high) == 0:
        return []
    groups = [[int(high[0]), int(high[0])]]
    for frame in high[1:]:
        value = int(frame)
        if value - groups[-1][1] - 1 <= MAX_GAP_FRAMES:
            groups[-1][1] = value
        else:
            groups.append([value, value])
    spans = []
    for first, last in groups:
        if last - first + 1 < MIN_SPAN_FRAMES:
            continue
        start, end = first * FRAME, min(sample_count, (last + 1) * FRAME)
        spans.append({"start_sample": start, "end_sample": end,
                      "start_seconds": round(start / SR, 3),
                      "end_seconds": round(end / SR, 3)})
    return spans

06 | Source code and evidence

The evidence supports genuine pretrained neural CPU inference, the resulting per-frame probabilities, timestamp conversion and independent replay for this fixed fixture. It does not establish speech detection precision, recall, speaker identity, transcript accuracy, multilingual robustness or production latency guarantees. In particular, nine output spans are not nine ground-truth speech intervals.

Data and licensing boundary: the real recording and model weights are downloaded in the ephemeral test environment. Their separate redistribution rights were not established here; the public site does not redistribute the audio or weights. The experiment's simple threshold postprocessor is not equivalent to Silero's production algorithm.
