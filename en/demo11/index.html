01｜The practical question

Speech recognition must transcribe acoustic samples rather than recover a text string from the file name. A genuine ASR test separates the input waveform from the reference transcript used only after inference.

02｜How the system works

espeak-ng first synthesizes a real WAV waveform, then pretrained Whisper tiny.en is loaded through faster-whisper/CTranslate2 on CPU. The expected phrase is held out of the model input and used only for post-inference checks.

02Run Whisper tiny.en
03Decode actual text
04Check post-inference words

03｜Experiment inputs and execution

The synthesized spoken phrase is 'The quick brown fox jumps over the lazy dog.' The script records WAV duration, hash and actual model transcription, then checks that at least three of quick, fox, lazy and dog appear.

04｜What acceptance actually observed

The dedicated Actions run successfully executed pretrained tiny.en inference on audio data, writing REAL_WHISPER_ASR_CPU_E2E_PASS and preserving the WAV and actual transcription without a template-response substitute.

06｜Limits and future deepening

A single synthetic English TTS sample is not spontaneous human speech. No real-world WER benchmark, multilingual quality, noisy speech robustness, diarization or immutable model pin was tested.
