Tracing distributed requests with OpenTelemetry and Jaeger

A single request may travel through a gateway and backend process; isolated logs do not show the entire path. Distributed tracing links spans into one trace so developers can follow propagation, service boundaries and failure locations.

01 · The problem this technology solves

A single request may travel through a gateway and backend process; isolated logs do not show the entire path. Distributed tracing links spans into one trace so developers can follow propagation, service boundaries and failure locations.

02 · Core mechanism

The gateway and backend are separate OS processes propagating W3C traceparent and exporting OTLP/HTTP Protobuf through official SDK code. After an initial local protocol-probe test, a later Docker Actions run starts an actual Collector and Jaeger and queries recorded traces back.

03 · What the experiment actually ran

The Docker stack launches gateway, backend, Collector and Jaeger, submits six HTTP requests, then queries six trace IDs to verify service and business-span evidence. The earlier probe also retained raw .pb batches, decoded JSONL spans and request logs.

04 · Observed acceptance evidence

The dedicated Docker Actions job succeeded with six Collector-to-Jaeger trace readbacks. Older 'Docker unavailable locally' wording describes a previous workstation-stage constraint and does not supersede this verified cloud result.

05 · Reproduce the experiment

From the repository root, use the experiment's documented runner. This snippet is a reference command, not a live in-browser executable.

cd projects/03-opentelemetry
python -m pip install -r requirements.txt
python scripts/run_compose_e2e.py

Model downloads, external tools, OS-specific requirements and permissions are described in the private project.

06 · Limits and the next deeper question

Synthetic business traffic, loopback endpoints and in-memory Jaeger storage only. Inter-host tracing, persistent storage, protected production traffic, sampling, scale and availability SLOs are out of scope. The UI trace API is not a stable public contract.
