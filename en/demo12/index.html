1. Requirements and acceptance

Run an actual pretrained torchvision ResNet18 on a synthetic PNG and inspect 1,000-class logits and Top5 probabilities. The acceptance target is real CPU inference, valid tensor shapes and normalized softmax, not classification correctness for an out-of-distribution illustration.

2. Technical design and data flow

Pillow generates a 256×256 geometric fixture and records its SHA-256. The pretrained weights supply their own preprocessing transforms, producing [1,3,224,224] tensors. Model logits have shape [1,1000]; softmax yields probabilities, and class names come from the weight metadata.

3. Core code and implementation details

3.1 Weights and input preprocessing

Source：verify_vision.py — Selected excerpt, surrounding context omitted; not standalone executable

weights = ResNet18_Weights.IMAGENET1K_V1
model = resnet18(weights=weights).eval().cpu()
preprocess = weights.transforms()
inputs = preprocess(Image.open(path).convert("RGB")).unsqueeze(0)
assert list(inputs.shape)==[1,3,224,224]

Use the preprocessing contract supplied by the weight enum; raw RGB pixels are not a valid replacement. eval() selects inference behavior and unsqueeze(0) inserts the batch dimension. Weight changes may require different transforms and category labels.

3.2 Logits, softmax and Top5

Source：verify_vision.py — Selected excerpt, surrounding context omitted; not standalone executable

with torch.inference_mode():
    logits = model(inputs)
    probs = torch.softmax(logits,dim=1)[0]
assert list(logits.shape)==[1,1000]
assert abs(float(probs.sum())-1) < 1e-4
top = torch.topk(probs,k=5)

Logits are unnormalized class scores; softmax probabilities sum to approximately one. Top5 is relative model preference rather than ground truth. Labels such as “bolo tie” on the synthetic shape are not evidence of correct semantic classification.

5. Integration and operational use

For a classifier service, keep the matching preprocessing transform, validate image dimensions and RGB mode, and record model version, TopK and latency. Evaluate on labeled business images before using class decisions. Detection, segmentation and multi-label output are out of scope.
