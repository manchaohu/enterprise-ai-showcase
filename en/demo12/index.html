01｜The practical question

Whole-image classification assigns scores across a fixed category vocabulary to an entire image. It differs from locating multiple objects with bounding boxes or assigning semantic labels to individual pixels.

02｜How the system works

The code loads genuine torchvision ResNet18_Weights.IMAGENET1K_V1, applies the weights-provided image transforms and runs real CPU inference. The model produces 1,000 class logits, softmax probabilities and a Top-5 label list.

03｜Experiment inputs and execution

A 256×256 synthetic PNG with geometric shapes is saved then reopened. The runner checks tensor input [1,3,224,224], logits [1,1000], finite probabilities summing to one, and retains predicted Top-5 labels and source hash.

04｜What acceptance actually observed

The actual pretrained forward pass succeeded with PRETRAINED_VISION_CPU_E2E_PASS. Evidence explicitly records accuracy_assessed=false because the synthetic geometric image is not a labeled ImageNet accuracy example.

06｜Limits and future deepening

A real forward pass does not establish semantic correctness. The demo contains no real-photo accuracy benchmark, object detection, segmentation, VLM interaction or production SLO; wheels are not fully hash-pinned.
