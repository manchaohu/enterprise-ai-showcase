From rectangles to pixel-level semantic regions

A real SegFormer B0 semantic segmentation experiment: why bounding boxes are not enough, how per-pixel labels are produced, and how evidence is checked.

← Back to all tutorials

01 | Why detect regions rather than just boxes?

An object detector locates candidates by drawing rectangles. Yet those rectangles also include sky, road or surrounding objects. For tasks that need to identify the road surface, building area or other image regions, we need finer spatial information.

Semantic segmentation assigns a predicted class to every pixel. Pixels labeled “road” share the same semantic category, while pixels labeled “sky” belong to another class. This approach describes regions, but it does not necessarily distinguish individual objects of the same class.

02 | The difference is visible in the output format

Object detection

Outputs rectangular coordinates, class labels and scores. Boxes may contain background.

Semantic segmentation

Outputs a class-ID mask aligned to image dimensions, with a predicted category for each pixel.

Interpolate logits to image size
4. Classify pixels
Argmax over category scores

The experiment uses a pretrained SegFormer B0 checkpoint fine-tuned on ADE20K. The network produces per-class logits at spatial positions. The pipeline aligns them back to the original image dimensions and applies argmax across classes. The resulting mask stores a category ID per pixel; it is not a list of bounding boxes.

05 | Semantic and instance segmentation are different

Semantic segmentation assigns the same category to all pixels that belong to cars, for example, but it does not necessarily label car #1 separately from car #2. Instance segmentation requires an individual mask for each instance. Demo 25 implements the former, not the latter.

Scope limits: no independently annotated mIoU, boundary-error or generalization benchmark has been completed. The pretrained model's and source images' commercial use and redistribution rights need separate review. A teaching illustration cannot be treated as quality evidence.
