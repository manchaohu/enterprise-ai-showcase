01｜The practical question

A vision-language model should use the supplied image pixels when answering a natural-language question. Holding the question constant while changing image color offers a narrow causal test of visual input use.

02｜How the system works

Genuine pretrained HuggingFaceTB/SmolVLM-256M-Instruct runs on CPU with two Pillow PNG inputs that differ only in a red versus blue square. Both receive the same text question; the generated answers are independently checked against pixel evidence.

02Load pixels into SmolVLM
03Ask identical question
04Verify generated colors

03｜Experiment inputs and execution

Two 512×512 synthetic images contain identical shapes and background but different square colors. The expected color and image file names are withheld from the prompt. Input hashes, tensor details and generated answers are retained.

04｜What acceptance actually observed

Actual pretrained outputs were Red and Blue for the corresponding two images. The dedicated and follow-up Actions runs passed, storing original PNGs and verification records.

06｜Limits and future deepening

Two synthetic color squares do not establish broad image reasoning, complex real-world VLM quality, multi-turn understanding or production accuracy. The model revision remains a moving main.
