1. Requirements and acceptance

Supply two differently colored synthetic images and ask the exact same English question. Validate that the vision model receives nonempty pixel tensors and returns the corresponding color. The task tests image-conditioned generation, not general natural-image understanding.

2. Architecture and execution path

Pillow constructs 512×512 white-background images with a large colored square. AutoProcessor builds multimodal tensors from the image and chat template; SmolVLM-256M-Instruct generates on CPU. The verifier records image hashes, pixel-tensor presence and decoded answers for red and blue.

3. Core implementation

3.1 Build synthetic image fixtures

Source：vlm_e2e.py · Selected excerpt; full logic in repository

image = Image.new("RGB", (512, 512), "white")
ImageDraw.Draw(image).rectangle((40, 40, 471, 471), fill=rgb)
image.save(destination, format="PNG")

The fixture controls size, background and shape while varying the square color. This isolates a simple visual cue but removes most natural-image complexity; success is not a general VQA result.

3.2 Prepare image-conditioned tensors

Source：vlm_e2e.py · Selected excerpt; full logic in repository

processor = AutoProcessor.from_pretrained(MODEL_ID,
    size={"longest_edge": 512})
messages = [{"role":"user", "content":[
    {"type":"image"}, {"type":"text", "text":QUESTION}]}]
prompt = processor.apply_chat_template(messages, add_generation_prompt=True)
inputs = processor(text=prompt, images=[im.convert("RGB")],
                   return_tensors="pt")
assert inputs["pixel_values"].numel() > 0

The model-specific processor handles the image placeholder and emits pixel_values. Checking a nonempty pixel tensor prevents accidental text-only tests. Other VLM families often require different processors and chat templates.

3.3 Decode output and evaluate answer

Source：vlm_e2e.py · Selected excerpt; full logic in repository

generated_ids = model.generate(**inputs, max_new_tokens=36,
    do_sample=False, pad_token_id=processor.tokenizer.eos_token_id)
new_ids = generated_ids[0][inputs["input_ids"].shape[-1]:]
answer = processor.decode(new_ids, skip_special_tokens=True).strip()

The prompt-token prefix is removed before decoding new generation, preventing the question text from contaminating the answer. do_sample=False makes this small experiment more stable. Simple word matching is suitable for this color test, not open-ended reasoning evaluation.

In a real image-understanding service, validate upload size, visual token budget and image provenance. Preserve image hashes, model revision and prompts. Add task datasets for multiple objects, OCR, occlusion and hallucination before using answers in consequential decisions.

6. Limits and evidence

Only two synthetic high-contrast squares and one English question were tested. The original model request used moving main, despite a resolved commit being recorded. Broader accuracy remains unmeasured.
