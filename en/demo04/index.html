Hybrid search: combining lexical and latent signals

Keyword matching preserves exact terms but can miss alternate wording, while similarity-based ranking can overlook precise identifiers. A hybrid retriever combines multiple independent rank signals before presenting results.

← All 27 demos

01 · The problem this technology solves

Keyword matching preserves exact terms but can miss alternate wording, while similarity-based ranking can overlook precise identifiers. A hybrid retriever combines multiple independent rank signals before presenting results.

02 · Core mechanism

The implementation uses a real rank-bm25 lexical index and TF-IDF followed by truncated SVD to build latent vectors. Cosine similarity, reciprocal rank fusion (RRF) and a transparent phrase-match reranker combine signals. These are not pretrained neural embeddings.

03 · What the experiment actually ran

Five synthetic English technical snippets cover MCP, OpenTelemetry, OCR, hybrid retrieval and async queues. Five fixed queries exercise both ranking signals, preserve Top-3 results and assert the expected source appears at position one.

04 · Observed acceptance evidence

Precision@1 was 1.0 across the five deliberately constructed queries. The real ranking algorithms executed and recorded lexical/latent signals; the number is a narrow smoke-test outcome, not a representative retrieval benchmark.

05 · Reproduce the experiment

From the repository root, use the experiment's documented runner. This snippet is a reference command, not a live in-browser executable.

cd projects/04-hybrid-rag
python -m pip install -r requirements.txt
python verify_hybrid.py

Model downloads, external tools, OS-specific requirements and permissions are described in the private project.

06 · Limits and the next deeper question

No pretrained neural embedding, LLM generation, learned Cross-Encoder or real multilingual corpus. Five synthetic queries cannot establish realistic Recall@k, ranking quality or robustness.
