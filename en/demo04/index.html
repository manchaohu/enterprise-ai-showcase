1. Requirements and acceptance

Combine lexical matching and low-dimensional latent-vector similarity over business documents. Return source paths, document IDs and scores. Five constructed queries target MCP, OTel, OCR, hybrid search and queues; all five expected documents must rank first. The vector branch is character TF-IDF + TruncatedSVD, not a neural embedding model; no LLM answer generation is involved.

2. Technical design and data flow

HybridIndex builds BM25 tokens and a character TF-IDF matrix, then applies truncated SVD and L2 normalization. Each query produces independent lexical and latent rankings. RRF sums reciprocal ranks, while an exact phrase match receives a manual +0.02 boost. This is an explicit heuristic, not a trained cross-encoder. Keeping both component scores is useful for diagnosing poor rankings.

3. Core code and implementation details

3.1 Index construction

Source：hybrid_retrieval.py — Selected excerpt, surrounding context omitted; not standalone executable

self.bm25 = BM25Okapi(self.words)
self.vectorizer = TfidfVectorizer(analyzer="char", ngram_range=(2, 3))
tfidf = self.vectorizer.fit_transform([d["text"] for d in docs])
dim = min(8, min(tfidf.shape) - 1)
self.svd = TruncatedSVD(n_components=dim, random_state=17)
self.embeddings = normalize(self.svd.fit_transform(tfidf))

BM25 is built over token sequences. Character n-grams capture substrings, though this small corpus does not validate production Chinese tokenization. The chosen dim stays below the available matrix rank; a fixed SVD seed supports repeatability. Normalized latent vectors can be compared with a dot product. Index refresh and persistence are not implemented.

3.2 Rank fusion and final sorting

Source：hybrid_retrieval.py — Selected excerpt, surrounding context omitted; not standalone executable

lex_rank = {int(idx): rank + 1 for rank, idx in enumerate(lexical_order)}
vec_rank = {int(idx): rank + 1 for rank, idx in enumerate(dense_order)}
rrf = 1/(60+lex_rank[i]) + 1/(60+vec_rank[i])
phrase = int(query.casefold() in doc["text"].casefold())
score = rrf + 0.02 * phrase

RRF uses ranks rather than combining differently scaled raw scores. The constant 60 moderates differences in top positions. The +0.02 phrase bonus can dominate small rank-score changes in this miniature corpus. Sorting is deterministic with document-ID tie breaks. This heuristic is distinct from Demo 19 neural reranking.

5. Integration and operational use

In a search service, separate ingestion, text splitting, lexical indexing, embedding retrieval and candidate reranking. Replace the toy latent representation only after evaluating real encoders and retrieval quality. Measure recall, human relevance labels, latency and index updates; reranking cannot recover a document never retrieved.
