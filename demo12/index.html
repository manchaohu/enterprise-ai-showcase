Demo 12｜ResNet18 图片分类：预训练推理与 Top5 输出

公开在线审读候选（仍待该篇人工内容验收） · 源代码位于私有工程仓库 · 实验结论只适用于声明的验证范围

原始源码（需访问权限）：12-real-vision　 Actions Run：39351675033

1. 技术需求与验收

把一张程序生成的图像送入 torchvision 预训练 ResNet18，输出 1,000 类分类 logits 和 Top5 概率。目的在于验证权重真正加载、图片确实经过预处理和模型前向推理、概率满足归一化约束。构造图不对应 ImageNet 真实类别，因而不评价分类是否正确。

2. 技术方案和数据链路

测试使用 Pillow 生成 256×256 彩色几何图，保存 SHA-256；ResNet18_Weights.IMAGENET1K_V1 包含与权重配套的 weights.transforms()，把图像转成网络需要的 [1,3,224,224] 张量；模型输出 [1,1000]，经 softmax 得到概率。分类标签来自 weights 的 categories 元信息。

3. 核心实现及关键代码

3.1 预训练权重与输入张量

对应源码：verify_vision.py — 关键代码节选（省略上下文，不可直接独立执行）

weights = ResNet18_Weights.IMAGENET1K_V1
model = resnet18(weights=weights).eval().cpu()
preprocess = weights.transforms()
inputs = preprocess(Image.open(path).convert("RGB")).unsqueeze(0)
assert list(inputs.shape)==[1,3,224,224]

必须使用与权重匹配的 transforms：其中包含 resize、crop、归一化等约定，不能把原始 RGB 像素数组直接输入 ResNet。eval() 关闭训练行为，unsqueeze(0) 添加入 batch 维。更新权重版本时预处理参数和分类标签都应同步检查。

3.2 Logits、softmax 和 Top5

对应源码：verify_vision.py — 关键代码节选（省略上下文，不可直接独立执行）

with torch.inference_mode():
    logits = model(inputs)
    probs = torch.softmax(logits,dim=1)[0]
assert list(logits.shape)==[1,1000]
assert abs(float(probs.sum())-1) < 1e-4
top = torch.topk(probs,k=5)

logits 是未归一化分类分数；softmax 后 1,000 项和应接近 1。Top5 只表示相对排序，不自动代表检测到“真实目标”。测试图得到 bolo tie 等标签，属于分布外输入导致的模型判断，不应该描述为正确分类结果。

4. 实验结果与证据

归档 PRETRAINED_VISION_CPU_E2E_PASS，输入张量 [1,3,224,224]、输出 [1,1000]、概率和为 1.0。Top1 为 bolo tie、概率 0.19632，后续还有 loupe、nematode 等。构造图缺乏 ImageNet 真值，不具备准确率计算基础。

5. 工程使用与集成

集成实际分类服务时，复用权重配套 transform，统一 RGB 与尺寸，控制输入文件大小，记录版本、TopK 和推理耗时。数据类型迁移到企业图片后，必须建立标注验证集，必要时微调/重训分类头。目标检测、分割和多标签分类都不是 ResNet18 此 Demo 的输出。
