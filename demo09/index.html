Demo 09｜图像与音频信号处理：像素统计、FFT 与 WAV 检查

公开在线审读候选（仍待该篇人工内容验收） · 源代码位于私有工程仓库 · 实验结论只适用于声明的验证范围

原始源码（需访问权限）：09-multimodal-media　 Actions Run：39262917950

1. 技术需求与验收

将 PNG 图片和 WAV PCM16 作为真实文件打开并计算基础统计，为后续视觉分类、音频识别或实时交互建立预处理能力。测试程序生成一张 120×80 彩色图，以及一段 16kHz、1 秒、440Hz 正弦波；验证尺寸、红色像素数、RMS 和频谱峰值。该模块没有视觉模型或语音识别模型。

2. 技术方案和数据链路

图片经 Pillow 解码并转换 RGB 数组，计算逐通道均值和满足阈值条件的红色像素数。音频经 wave 读取并检查单声道 16-bit 格式，再归一化为 [-1,1]，用 np.fft.rfft 找最高非零频率能量 bin，同时计算波形 RMS。测试由公式构造输入，归档保存 PNG/WAV 和数值证据。

3. 核心实现及关键代码

3.1 图像颜色特征

对应源码：media_pipeline.py — 关键代码节选（省略上下文，不可直接独立执行）

pixels = rgb.reshape(-1, 3)
means = pixels.mean(axis=0)
red_pixels = int(np.sum((pixels[:,0]>180) &
    (pixels[:,0]>pixels[:,1]*1.4) &
    (pixels[:,0]>pixels[:,2]*1.4)))

reshape(-1,3) 让每行对应一个 RGB 像素，均值是整图颜色统计。红色规则要求 R 超过固定亮度阈值且显著高于 G/B，它只是针对已知色块的手写像素过滤器，既不能替代目标检测也不能处理复杂光照下的语义“红色物体”。

3.2 FFT 峰值与 RMS

对应源码：media_pipeline.py — 关键代码节选（省略上下文，不可直接独立执行）

data = np.frombuffer(handle.readframes(handle.getnframes()), dtype="<i2")
signal = data.astype(np.float64) / 32768
spectrum = np.abs(np.fft.rfft(signal))
freqs = np.fft.rfftfreq(len(signal), 1/rate)
peak = int(np.argmax(spectrum[1:]) + 1)

<i2 表示小端有符号 16 位样本，除以 32768 转成浮点幅度。rfft 仅处理实信号非冗余正频谱，故排除索引 0 的直流分量。最大峰只能识别主导频率，无法识别语音内容；噪声、多声源和窗函数泄漏需要更复杂的谱分析。
