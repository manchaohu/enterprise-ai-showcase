01｜技术需求：逐像素语义类别

前一个实验的 YOLO 能定位物体，告诉我们矩形框大致覆盖哪些对象。但矩形框包括背景：路面、天空或其他物体也可能落在框内。假设我们关心的是道路可通行区域、建筑轮廓或图像中的每一片地表，矩形框就不够精确。

语义分割的任务是让模型为图像中的每个像素预测一个类别。 属于“道路”的像素共享同一类别，属于“天空”的像素共享另一类别。它关注区域含义，而不是分别给同一类别的每个物体独立编号。

主要输出：类别、置信度、矩形坐标。

语义分割（Demo 25）

主要输出：与原图同宽高的类别掩码；每个像素对应一个类别 ID。

03｜SegFormer 推理与掩码生成

① 图像准备
读取照片，转换为模型所需输入
② SegFormer 推理
CPU 前向执行预训练神经网络
③ 像素对齐
将 logits 插值回原图大小
④ 类别决策
每像素取最高类别得分并生成 PNG 掩码

本实验用的是 SegFormer B0（ADE20K 微调权重）。模型会为图像的空间位置输出各类别分数（logits），经过上采样对齐原始照片宽高，再对类别维度取 argmax。结果可以保存为灰度类别索引图，每个像素值是一个类别 ID，而不是目标框。

04｜预训练模型的实测证据

真实运行源码节选，完整代码见私有仓库：projects/25-real-segmentation/segment_e2e.py

模型分类分数恢复至原图分辨率

`SegformerImageProcessor` 负责图像预处理，模型输出类别 logits。先使用双线性插值将连续 logits 恢复到原始宽高，再沿类别维 `argmax` 选最可能的语义类别，生成每像素整数标签。不要直接把离散类别图拿来插值。

def inference(img, processor, model):
    inputs = processor(images=img, return_tensors="pt")
    with torch.inference_mode():
        logits = model(**inputs).logits
        resized = torch.nn.functional.interpolate(logits, size=(img.height, img.width), mode="bilinear", align_corners=False)
        mask = resized.argmax(dim=1)[0].cpu().numpy().astype(np.uint8)
    return logits.cpu().numpy(), mask

原始 logits、标签掩码与像素校验

将类别 ID 掩码保存 PNG，原始数值 logits 保存在 NPZ；`np.bincount` 统计每类像素数，校验总数等于图像面积。掩码是类别索引，不是自动生成的人眼友好彩图。第三方原始照片用后删除，不在 Artifact 传播。

def main():
    torch.set_num_threads(2)
    OUT.mkdir(exist_ok=True)
    rev = HfApi().model_info(MODEL).sha
    processor = SegformerImageProcessor.from_pretrained(MODEL, revision=rev)
    model = SegformerForSemanticSegmentation.from_pretrained(MODEL, revision=rev).eval().cpu()
    photo = Path("artifacts/_source.jpg")
    urllib.request.urlretrieve(PHOTO, photo)
    image = Image.open(photo).convert("RGB")
    raw, mask = inference(image, processor, model)
    # This transparent-free indexed mask is a direct model pixel classification, not a mock drawing.
    Image.fromarray(mask).save(OUT / "semantic_mask.png")
    np.savez_compressed(OUT / "raw_logits.npz", logits=raw)
    counts = np.bincount(mask.ravel(), minlength=int(model.config.num_labels))
    classes = [{"id":int(i),"name":str(model.config.id2label[i]),"pixels":int(v)}
               for i,v in enumerate(counts) if v]
    evidence = {
        "model":MODEL, "model_revision":rev, "source_url":PHOTO,
        "source_sha256":sha256(photo), "size":[image.width,image.height],
        "logits_shape":list(raw.shape), "mask_shape":list(mask.shape),
        "mask_sha256":sha256(OUT / "semantic_mask.png"),
        "classes":classes, "pixel_total":int(mask.size),
        "processor":processor.to_dict(), "torch_version":torch.__version__
    }
    (OUT / "segmentation_evidence.json").write_text(json.dumps(evidence, indent=2, default=str))
    # Source third-party photograph is not redistributed.
    photo.unlink()
    assert len(classes)>1 and sum(c["pixels"] for c in classes)==image.width*image.height
