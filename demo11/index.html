1. 技术需求与验收条件

将一段实际 WAV 语音输入预训练 ASR 模型，返回文字及可核对的证据。测试音频由 espeak-ng 合成朗读英文句子，Whisper 模型不接收参考文本；识别结束后才用关键词评估结果。这样可以验证声音文件确实经过 ASR 推理。

2. 技术方案与执行链

espeak-ng 生成单声道 WAV，wave 检查声道和帧数，faster-whisper 使用 CTranslate2 加载 tiny.en 英语预训练模型，以 CPU int8 执行解码。segments 迭代拼接为完整转录字符串；最后保存音频 SHA-256、长度、识别结果及关键词命中情况。

3. 核心实现与代码要点

3.1 合成测试语音及文件检查

源码位置：verify_asr.py · 关键片段（其余逻辑见完整源码）

subprocess.run(["espeak-ng", "-v", "en-us", "-s", "145",
                "-w", str(wav), PHRASE], check=True)
with wave.open(str(wav), "rb") as reader:
    assert reader.getnchannels() == 1
    duration = reader.getnframes() / reader.getframerate()

该 WAV 是通过合成语音产生的真实音频数据，但不等于真实人的自然语音。-s 145 配置合成语速；check=True 确保生成工具异常会中止验收。保留文件哈希可以辨别输入是否被替换。文件头的通道和帧数检查不包含信号质量或语义有效性判断。

3.2 Whisper 模型转录

源码位置：verify_asr.py · 关键片段（其余逻辑见完整源码）

model = WhisperModel("tiny.en", device="cpu", compute_type="int8")
segments, info = model.transcribe(
    str(wav), language="en", beam_size=5,
    vad_filter=False, condition_on_previous_text=False)
observed = " ".join(part.text.strip() for part in segments).strip()

tiny.en 为英语专用小模型，适合 CPU 链路演示；int8 降低权重计算资源需求。beam_size=5 控制解码候选搜索；vad_filter=False 不在输入前使用内置语音活动过滤；condition_on_previous_text=False 关闭连续片段历史文本条件，适合独立短句。生产长音频需要处理切段、时间戳、VAD 与语种。

3.3 关键词验收及证据记录

源码位置：verify_asr.py · 关键片段（其余逻辑见完整源码）

words = set(re.findall(r"[a-z]+", observed.lower()))
required = ["quick", "fox", "lazy", "dog"]
matched = [w for w in required if w in words]
assert len(matched) >= 3

验收是关键词命中至少三个，并非句子级完全相同或 WER 达标。实际输出出现 jump 而不是原句 jumps，说明有细微识别差异。关键词集合也会丢失词序和重复词信息；需要评估语言质量时应加入人工标注参考和完整 WER/CER 指标。
