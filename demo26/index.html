说话人向量：已知语音片段属于谁？

01｜技术为什么有用

语音转文字回答的是“说了什么”，而多人会话还需要区分“是谁说的”。最小实验可以从已经知道每一段起止时间的语音出发，比较预训练说话人向量的相似程度。

02｜核心技术与处理流程

使用真正的 SpeechBrain spkrec-xvect-voxceleb 预训练模型对已切分片段执行 CPU 神经推理，提取 X-vector 表征，通过余弦相似度归属已知说话人，并独立核对保存的数值。

03｜真实执行的实验过程

对三段已知边界的音频进行预训练向量推理与相似度对照，得到受限的说话人归属结果。早期 README 只有预检步骤，后续专项 E2E 已完成模型推理，两个阶段不可混淆。

04｜已观测结果与验收证据

专项 Actions 确认真实预训练 X-vector 和独立数值证据通过。它建立了已知片段条件下的基础说话人归属能力，不应直接标为完整、盲切分的说话人分离系统。

06｜能力边界与后续深化

三段音频没有覆盖未知话轮边界、重叠发言、多语言泛化或标准 Diarization Error Rate（DER）；不声明生产说话人识别准确率或底层音频的商业再分发权。
