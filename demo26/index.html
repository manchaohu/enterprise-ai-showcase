Demo 26｜说话人 X-vector：已知分段的声纹相似度与归属

公开在线审读候选（仍待该篇人工内容验收） · 源代码位于私有工程仓库 · 实验结论只适用于声明的验证范围

原始源码（需访问权限）：26-speaker-diarization　 Actions Run：39441717044

1. 技术需求与验收

给定三段已经知道边界的语音片段：说话人 A 的第一句、说话人 B 的一句、A 的第二句。程序用真实 SpeechBrain X-vector 模型生成每段声纹向量，把第三段与前两段分别计算余弦相似度，并分配给相似度更高的参考说话人。这里分段边界是预先给定的，不是从混合录音中自动发现。

2. 技术方案和数据链路

程序从 SpeechBrain 公共样本地址读取三条 WAV，保存原文件 SHA-256，但不在 Artifact 中再次发布录音。统一转为 16kHz 单声道并限长 6 秒；EncoderClassifier.encode_batch 推理提取向量，再转为 L2 单位向量。对第三段分别比较前两段，选择 A 或 B，最后组装来源、时间边界、预测 ID 和参考 ID 的时间段列表。

3. 核心实现及关键代码

3.1 规范化声纹和余弦相似度

对应源码：diarize_e2e.py — 关键代码节选（省略上下文，不可直接独立执行）

v = classifier.encode_batch(wave.unsqueeze(0)).detach().cpu().numpy()
embeddings.append(unit(v))
# unit(): vector / np.linalg.norm(vector)
sims = [cosine(embeddings[2], embeddings[j]) for j in (0,1)]
predicted = 0 if sims[0] >= sims[1] else 1

声纹向量是说话人相关特征表示，不等于个人身份证明。单位化使比较忽略整体幅度，用点积衡量方向接近程度。第三段的参考标签并未直接用于 predicted 赋值，而是后验计算“已知分段准确率”；相同说话人在不同录音条件下可能仍有显著误差。

3.2 时间段组装与验证

对应源码：diarize_e2e.py — 关键代码节选（省略上下文，不可直接独立执行）

dur = int(wave.numel())
label = [0,1,predicted][i]
segments.append({"start_s": audio_start/SR,
                 "end_s":(audio_start+dur)/SR,
                 "speaker_id":f"SPEAKER_{label}"})
audio_start += dur

start_s/end_s 来源于拼接既有片段的采样点数量，属于已知边界计算，而不是 VAD 自动断句。真实会议说话人分离还需 VAD、重叠声检测、说话人数估计、聚类和后处理。测试用名为 speaker_accuracy_known_turns，避免被误读成完整 diarization DER。

5. 工程使用与集成

可用于已切好短片段的说话人相似性判断或受控声纹特征研究。接入真实会议录音还需前置 VAD/分段、声道与采样率统一、短语音过滤、聚类阈值校准，以及个人声音数据的隐私保护和处理授权。未经额外验证不得作为生物认证或员工身份确认依据。
