Demo 10｜神经文本 Embedding：句向量生成、归一化与余弦比较

1. 技术需求与验收

将四条英文句子输入真实预训练句向量模型，输出数值向量并计算相似度。两组句子分别描述狗在公园奔跑、SQLite 数据库事务；目标是同义句得分高于跨主题组合，同时检查向量维度、范数及重复调用稳定性。该 Demo 专门验证真实神经 Embedding 的 CPU 推理链路。

2. 技术方案和数据链路

SentenceTransformer 加载 sentence-transformers/paraphrase-MiniLM-L3-v2，CPU 端一次批量编码四个字符串。normalize_embeddings=True 将向量归一化，结果矩阵尺寸为 [4,384]。因为范数接近 1，向量点积即可表示余弦相似度。对输入排列、模型版本和归一化方式有显式约束；模型 revision 请求 main，未固定不可变版本。

3. 核心实现及关键代码

3.1 向量生成与规范化

对应源码：verify_embedding.py — 关键代码节选（省略上下文，不可直接独立执行）

model = SentenceTransformer(MODEL_ID, revision="main", device="cpu")
vec = model.encode(sentences, normalize_embeddings=True,
  convert_to_numpy=True, show_progress_bar=False)
assert vec.ndim == 2 and vec.shape[0] == 4
norms = np.linalg.norm(vec,axis=1)
assert np.allclose(norms,1,atol=0.01)

归一化让文本间比较主要反映方向，而不是向量长度；convert_to_numpy=True 便于直接做矩阵计算。atol=0.01 给浮点计算容差，不能仅以范数合格证明语义质量。缓存索引或使用向量数据库时必须保存模型 ID、版本与维度，不能混用不同嵌入空间。

3.2 相似度矩阵与相对断言

对应源码：verify_embedding.py — 关键代码节选（省略上下文，不可直接独立执行）

scores = vec @ vec.T
assert scores[0,1] > scores[0,2]
assert scores[2,3] > scores[2,0]
again = model.encode([sentences[0]], normalize_embeddings=True,
  convert_to_numpy=True, show_progress_bar=False)[0]
assert np.allclose(again,vec[0],atol=1e-4)

两个不等式检查任务相关性排序是否满足预设，但不要求固定的余弦分数，避免误将某一数值当通用阈值。again 检查同一输入的复算稳定性。生产语义检索应使用标注检索集评价 Recall@k、nDCG，并按语种、文本长度和领域分组。

4. 实验结果与证据

证据 PRETRAINED_EMBEDDING_CPU_E2E_PASS，维度 [4,384]，四条向量范数均为 1.0。公园狗同义句余弦 0.80843，狗与数据库 0.05853，数据库相关句 0.64442，重复编码稳定。数字仅来自本次模型及输入，不代表适用于任意语料的相似度阈值。

5. 工程使用与集成

用于知识库检索时需要分块、模型版本绑定、批量吞吐、增量索引和语言能力评估。查询和文档必须使用兼容的嵌入模型；更新权重需重新计算旧索引或设计迁移方案。Embedding 是召回阶段的表征，可结合 BM25 和 Cross-Encoder 完整部署。
