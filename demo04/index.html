Demo 04｜混合检索：BM25、TF-IDF/SVD 与 RRF 排序

公开在线审读候选（仍待该篇人工内容验收） · 源代码位于私有工程仓库 · 实验结论只适用于声明的验证范围

原始源码（需访问权限）：04-hybrid-rag　 Actions Run：39209375328

1. 技术需求与验收

输入业务文档和检索词，合并字面匹配与低维潜在向量的相关性，再返回可追溯的文档 ID、来源路径和打分。五个构造查询分别指向 MCP、OpenTelemetry、OCR、混合检索和队列，验收为五个查询的 Top1 与预期一致。实现采用 BM25、字符 2–3 gram TF-IDF、TruncatedSVD 和 RRF；它没有调用神经 Embedding 模型，也没有把答案生成部分并入检索链路。

2. 技术方案和数据链路

HybridIndex 初始化时把文档分别转为 BM25 token 序列和 TF-IDF 稀疏矩阵，后者执行截断 SVD 并 L2 归一化。查询阶段分别排序两个检索通道，用 1/(60+rank) 累计互逆排名分数；如果原文包含完整查询短语，再加 0.02。这是一种透明的短语加权规则，绝不是训练过的 Cross-Encoder。业务落地时应当记录独立通道的 rank/score 以便解释错排。

3. 核心实现及关键代码

3.1 混合索引建立

对应源码：hybrid_retrieval.py — 关键代码节选（省略上下文，不可直接独立执行）

self.bm25 = BM25Okapi(self.words)
self.vectorizer = TfidfVectorizer(analyzer="char", ngram_range=(2, 3))
tfidf = self.vectorizer.fit_transform([d["text"] for d in docs])
dim = min(8, min(tfidf.shape) - 1)
self.svd = TruncatedSVD(n_components=dim, random_state=17)
self.embeddings = normalize(self.svd.fit_transform(tfidf))

BM25 建立词项频率统计；字符 n-gram 能覆盖英文子串及连续汉字，但该 demo 的小样本不能代表中文生产分词质量。dim 必须小于输入矩阵有效维数，避免小语料 SVD 失败。random_state=17 固定分解随机性，归一化后可用内积计算潜在向量余弦相似度。真实检索索引更新与持久化尚未实现。

3.2 排名融合与最终排序

对应源码：hybrid_retrieval.py — 关键代码节选（省略上下文，不可直接独立执行）

lex_rank = {int(idx): rank + 1 for rank, idx in enumerate(lexical_order)}
vec_rank = {int(idx): rank + 1 for rank, idx in enumerate(dense_order)}
rrf = 1/(60+lex_rank[i]) + 1/(60+vec_rank[i])
phrase = int(query.casefold() in doc["text"].casefold())
score = rrf + 0.02 * phrase

RRF 融合的是名次而非 BM25 与余弦的不同量纲原始分数；常数 60 会削弱头部排名差异。短语加权 0.02 在此小例子中的影响可能大于两个 RRF 项的细微差别。排序最后按得分降序并以 ID 处理并列，可复算。该“rerank”只是规则加权，不应与 Demo 19 真正的模型重排混淆。

5. 工程使用与集成

可在知识搜索服务中把文档采集与切分、BM25 索引、真实 Embedding 召回和候选重排拆成模块。在规模更大的项目里，需替换 TF-IDF/SVD 为经评价的向量表示方案，并测召回率、相关性标注、延迟和增量更新。若首阶段没有取回相关候选，后续重排也无从修复。
