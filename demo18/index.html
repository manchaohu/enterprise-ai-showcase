1. 技术需求与验收条件

把文档图片、已标注的 OCR 词和位置框输入已微调的 LayoutLMv3，预测每个词在表单中的角色（标题、问题、答案或其他）。本 Demo 使用 FUNSD 公开测试集的两份表单，验证多模态模型真实前向、词级标签对齐及结果统计。OCR 词和坐标已经由数据集提供，本程序不执行 OCR。

2. 技术方案与执行链

datasets.load_dataset() 读取 test[:2]，AutoProcessor(..., apply_ocr=False) 把图片、词和 [0,1000] 归一化矩形编码为 pixel_values、input_ids 和 bbox；AutoModelForTokenClassification 输出七类 BIO 标签 logits。由于 tokenizer 会把一个单词拆成多个 wordpiece，程序使用 word_ids() 选取每个原词的首个 Token 进行对齐和评分。

3. 核心实现与代码要点

3.1 校验词、框、标签对齐

源码位置：layout_e2e.py · 关键片段（其余逻辑见完整源码）

if len(words) != len(boxes) or len(words) != len(gold_tags):
    raise ValueError("Misaligned words / boxes / reference labels")
if (len(box) != 4 or any(type(x) is not int or
    not 0 <= x <= 1000 for x in box)):
    raise ValueError("Invalid normalized document bounding box")

模型依赖文字序列与图中位置正确对应；词数、框数和标签数不相等会导致错位监督。bbox 的 0–1000 标准化坐标用于编码词的空间关系。若企业 OCR 输出的是像素坐标，需要先按页面宽高归一化，并对裁剪、旋转后的坐标体系进行一致性处理。

3.2 处理器与模型前向

源码位置：layout_e2e.py · 关键片段（其余逻辑见完整源码）

processor = AutoProcessor.from_pretrained(MODEL_ID, apply_ocr=False)
encoded = processor(image, words, boxes=boxes, return_tensors="pt",
                    truncation=True, max_length=512)
with torch.inference_mode():
    logits = model(**encoded).logits
    probabilities = logits.softmax(dim=-1)

apply_ocr=False 显式禁用处理器内 OCR，因为现成词框来自 FUNSD 标注。max_length=512 可能截断较长表单的末尾词；本轮两份文件的统计显示无词截断。softmax(dim=-1) 转为七个标签的相对得分，再以 argmax 取预测类别；最高得分不代表校准后的业务置信概率。

3.3 原词对齐与标签评价

源码位置：layout_e2e.py · 关键片段（其余逻辑见完整源码）

aligned = first_wordpieces(encoded.word_ids(batch_index=0), len(words))
for pos, word_id in aligned:
    prob = probabilities[0, pos]
    label_index = int(prob.argmax().item())
    predicted.append({"word": words[word_id],
        "predicted_label": LABELS[label_index],
        "gold_label": LABELS[gold[word_id]]})

每个原词只使用第一个子词位置进行统计，避免多 Token 词重复计数。BIO 中 B- 表示实体片段开始，I- 为后续词，O 为其他；这些是分类标签，不自动组成键值对。原代码统计参考标签与预测标签完全相同的词比例，这是该样本的描述性指标，不是文档级抽取准确率或数据集公开榜单分数。
